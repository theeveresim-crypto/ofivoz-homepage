Bocina inteligente para notificaciones de pagos

Ofivoz es una solución tecnológica diseñada para ayudar a los comercios a recibir y escuchar notificaciones de pagos de forma rápida, clara y sencilla.

Cómo funciona

Ofivoz conecta las notificaciones de pago con un dispositivo de audio para facilitar la confirmación de las transacciones en el punto de venta.

1

Se realiza el pago

El cliente realiza un pago utilizando el método de pago disponible en el comercio.

2

Se recibe la notificación

La plataforma procesa la información necesaria para identificar la notificación correspondiente.

3

Ofivoz procesa el evento

Nuestro sistema procesa la notificación y la envía al dispositivo asociado al comercio.

4

Confirmación de audio

La bocina reproduce una notificación de audio para informar al comercio que se ha recibido un pago.

Una solución pensada para comercios

Ofivoz busca facilitar la gestión de pagos en establecimientos donde una confirmación rápida puede mejorar la operación diaria.

Notificaciones simples y accesibles

El sistema está diseñado para proporcionar una confirmación de audio que permita al personal del comercio conocer cuándo se ha recibido una notificación de pago.

El dispositivo puede utilizarse como una herramienta complementaria a las aplicaciones y sistemas de pago utilizados por el comercio.

Uso de datos de Google

Transparencia sobre el uso de información cuando un usuario conecta una cuenta de Google con Ofivoz.

Información utilizada

Cuando un usuario autoriza el acceso a determinados servicios de Google, Ofivoz utiliza únicamente la información necesaria para proporcionar la funcionalidad solicitada por el usuario.

  • La información se utiliza para procesar notificaciones relacionadas con el servicio.
  • No utilizamos los datos de Google para publicidad personalizada.
  • No vendemos la información de los usuarios.
  • El acceso puede ser revocado por el usuario desde su cuenta de Google.
  • El tratamiento de los datos está limitado a las finalidades descritas en nuestra política de privacidad.

Para obtener información detallada sobre el tratamiento de datos, consulte nuestra Política de Privacidad .
