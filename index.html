Ofivoz

Bocina inteligente para notificaciones de pagos

Ofivoz es una solución para comercios que permite recibir notificaciones de pagos y reproducirlas automáticamente mediante una bocina inteligente.

Cómo funciona

01
Conecta tu cuenta

El comercio autoriza de forma segura la conexión necesaria para el servicio.

02
Recibimos la notificación

El sistema identifica las notificaciones de pago relevantes.

03
Procesamos la información

Se procesa únicamente la información necesaria para generar la notificación.

04
La bocina avisa

La notificación se envía al dispositivo para reproducir el aviso.

Uso de datos de Google

Cuando un comercio conecta una cuenta de Google, Ofivoz utiliza los permisos autorizados únicamente para prestar la funcionalidad de notificaciones de pagos. El acceso se limita a la información necesaria para identificar y procesar dichas notificaciones. Ofivoz no vende la información de Google del usuario ni la utiliza para publicidad personalizada.
