Política de Privacidad

Última actualización: 17 de septiembre de 2026

En Ofivoz nos comprometemos a proteger la información de los usuarios y a utilizarla únicamente para proporcionar y mejorar nuestros servicios.

1. Sobre Ofivoz

Ofivoz es una solución tecnológica para comercios que permite recibir notificaciones relacionadas con pagos y reproducir dichas notificaciones mediante una bocina inteligente.

2. Información que recopilamos

Dependiendo de las funciones utilizadas por el usuario, podemos procesar información necesaria para proporcionar el servicio, incluyendo:

  • Información relacionada con las notificaciones de pago.
  • Monto de la transacción.
  • Fecha y hora de la transacción.
  • Información de referencia o identificación de la transacción.
  • Identificación del comercio o dispositivo asociado.
  • Registros técnicos necesarios para operar y mantener el servicio.

3. Uso de Google y Gmail API

Ofivoz puede utilizar servicios de Google y la API de Gmail cuando el usuario autoriza expresamente el acceso correspondiente.

El acceso a Gmail se utiliza únicamente para obtener y procesar la información necesaria para identificar las notificaciones relacionadas con pagos y proporcionar la funcionalidad solicitada por el usuario.

Ofivoz no utiliza los datos obtenidos mediante las APIs de Google para publicidad personalizada ni para vender información de los usuarios.

El uso y transferencia de información recibida de las APIs de Google cumple con las políticas aplicables de Google, incluyendo los requisitos de uso limitado de datos.

4. Datos de pago y registros

Para proporcionar el servicio, Ofivoz conserva determinados registros visibles dentro de la plataforma, incluyendo registros técnicos y registros relacionados con las notificaciones de pago.

Estos registros pueden incluir información como el monto, fecha, hora, referencia de la transacción y el dispositivo o comercio relacionado.

El sistema no está diseñado para conservar permanentemente el contenido completo de los correos electrónicos utilizados para procesar las notificaciones.

5. Finalidad del tratamiento

La información puede utilizarse para:

  • Proporcionar las notificaciones de pago.
  • Enviar información al dispositivo asociado al comercio.
  • Mantener registros de las transacciones procesadas.
  • Detectar errores y mantener la seguridad del servicio.
  • Mejorar la estabilidad y funcionamiento de Ofivoz.
  • Atender solicitudes de soporte.

6. Compartición de información

Ofivoz no vende ni alquila información personal de los usuarios.

La información podrá ser procesada por proveedores tecnológicos que sean necesarios para operar la infraestructura del servicio, siempre dentro de las finalidades correspondientes y bajo medidas razonables de protección.

7. Publicidad

Los datos obtenidos mediante Google APIs no se utilizan para publicidad personalizada ni para determinar perfiles publicitarios de los usuarios.

8. Seguridad

Ofivoz utiliza medidas técnicas y administrativas razonables destinadas a proteger la información contra acceso no autorizado, pérdida, alteración o divulgación indebida.

Ningún sistema conectado a Internet puede garantizar seguridad absoluta; por ello, trabajamos continuamente para mantener controles de seguridad adecuados.

9. Acceso y revocación del acceso de Google

El usuario puede retirar en cualquier momento la autorización concedida a Ofivoz desde la configuración de su cuenta de Google.

Cuando el acceso sea revocado, Ofivoz dejará de utilizar las credenciales correspondientes para acceder a los servicios autorizados de Google.

10. Conservación de información

Conservamos los registros necesarios durante el tiempo razonablemente necesario para proporcionar el servicio, mantener su seguridad, solucionar problemas y cumplir con obligaciones legales aplicables.

11. Derechos de los usuarios

Dependiendo de la legislación aplicable, los usuarios pueden solicitar información sobre sus datos, solicitar correcciones o solicitar la eliminación de información cuando corresponda.

Para realizar una solicitud, puede comunicarse con nosotros utilizando el correo indicado al final de esta política.

12. Cambios a esta política

Ofivoz puede actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en nuestros servicios, procesos o requisitos legales.

La versión vigente estará disponible en esta página.
