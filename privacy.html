Política de Privacidad

Última actualización: 17 de septiembre de 2026

Ofivoz proporciona una solución tecnológica de notificaciones de pagos mediante una bocina inteligente para ayudar a los comercios a recibir alertas de pagos.

1. Información que procesamos

Para proporcionar el servicio, Ofivoz procesa temporalmente la información necesaria para generar una notificación de pago.

La información procesada corresponde únicamente al monto del pago indicado en la notificación.

Ofivoz no procesa ni almacena información que identifique al cliente que realizó el pago.

2. No almacenamiento de datos

Ofivoz no almacena ni conserva los montos de pago, información de clientes, correos electrónicos ni otros datos utilizados para generar las notificaciones.

El monto del pago se procesa temporalmente únicamente para generar y enviar la notificación al dispositivo correspondiente. Una vez completado el procesamiento, dicha información no se conserva.

Ofivoz no mantiene una base de datos histórica de los pagos procesados mediante el servicio.

3. Uso de Google APIs y Gmail

Cuando el usuario autoriza el acceso correspondiente, Ofivoz utiliza las APIs de Google, incluyendo Gmail API, únicamente para obtener temporalmente la información necesaria para proporcionar las notificaciones de pago.

La información utilizada corresponde únicamente al monto del pago.

Ofivoz no utiliza la información obtenida de Gmail para publicidad personalizada, publicidad dirigida, venta de datos, creación de perfiles publicitarios ni otros fines no relacionados con la prestación del servicio.

Ofivoz no almacena ni conserva el contenido de los correos electrónicos procesados.

El uso y la transferencia de información recibida de las APIs de Google cumple con las políticas aplicables de Google, incluyendo los requisitos de uso limitado de datos.

4. Compartición de información

Ofivoz no vende, alquila ni comercializa información personal de los usuarios.

Ofivoz no comparte con terceros información sobre los clientes que realizan los pagos.

5. Seguridad

Ofivoz aplica medidas técnicas destinadas a proteger la información durante su procesamiento y transmisión. El acceso a los servicios está limitado a las operaciones necesarias para proporcionar las funcionalidades solicitadas.

6. Revocación del acceso

El usuario puede revocar en cualquier momento el acceso de Ofivoz a su cuenta de Google mediante la configuración de seguridad de su cuenta de Google.

7. Retención

Ofivoz no conserva los datos utilizados para generar las notificaciones de pago. La información se utiliza únicamente durante el tiempo necesario para completar el procesamiento de la notificación.

8. Derechos del usuario

Los usuarios pueden realizar consultas relacionadas con privacidad contactando a Ofivoz.

9. Cambios a esta política

Ofivoz puede actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en el servicio, requisitos legales o cambios técnicos. Cualquier actualización será publicada en esta página.
