Política de Privacidad

Última actualización: 17 de septiembre de 2026

Ofivoz proporciona una solución de notificaciones mediante una bocina inteligente para ayudar a los comercios a recibir alertas de pagos.

1. Información que procesamos

Para proporcionar el servicio, Ofivoz puede procesar temporalmente información necesaria para identificar y comunicar una notificación de pago al dispositivo correspondiente.

Esta información puede incluir datos contenidos en una notificación de pago, como el monto, fecha y hora, referencia de la transacción y la información necesaria para asociar la notificación con un dispositivo.

2. No almacenamiento de datos

Ofivoz no almacena ni conserva información obtenida de las cuentas de Gmail, correos electrónicos, notificaciones de pago, registros de transacciones, datos personales relacionados con los pagos ni otros datos procesados para generar las notificaciones.

La información necesaria para procesar una notificación se utiliza de forma temporal únicamente para prestar el servicio y posteriormente deja de estar disponible para Ofivoz.

Ofivoz no mantiene una base de datos histórica de las transacciones procesadas a través del servicio.

3. Uso de Google APIs y Gmail

Cuando el usuario autoriza el acceso correspondiente, Ofivoz utiliza las APIs de Google, incluyendo Gmail API, únicamente para obtener la información necesaria para proporcionar las notificaciones de pago solicitadas por el usuario.

Ofivoz no utiliza la información obtenida de Gmail para publicidad personalizada, publicidad dirigida, venta de datos, creación de perfiles publicitarios ni otros fines no relacionados con la prestación del servicio.

Ofivoz no almacena ni conserva el contenido de los correos electrónicos procesados.

El uso y la transferencia de información recibida de las APIs de Google cumple con las políticas aplicables de Google, incluyendo los requisitos de uso limitado de datos.

4. Compartición de información

Ofivoz no vende, alquila ni comercializa información personal de los usuarios. Como no se conservan los datos procesados para las notificaciones, Ofivoz no mantiene una base de datos de información de pagos para compartir con terceros.

5. Seguridad

Ofivoz aplica medidas técnicas destinadas a proteger la información durante su procesamiento y transmisión. El acceso a los servicios está limitado a las operaciones necesarias para proporcionar las funcionalidades solicitadas.

6. Revocación del acceso

El usuario puede revocar en cualquier momento el acceso de Ofivoz a su cuenta de Google mediante la configuración de seguridad de su cuenta de Google.

7. Retención

Ofivoz no conserva los datos utilizados para generar las notificaciones de pago. La información procesada se utiliza únicamente durante el tiempo necesario para completar la operación correspondiente.

8. Derechos del usuario

Los usuarios pueden solicitar información sobre el funcionamiento del servicio o realizar consultas relacionadas con privacidad contactando a Ofivoz.

9. Cambios a esta política

Ofivoz puede actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en el servicio, requisitos legales o cambios técnicos. Cualquier actualización será publicada en esta página.
